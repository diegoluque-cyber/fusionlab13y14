# Letras Andinas - Tienda virtual
Estructura inicial de e-commerce con ReactJS (Vite, Tailwind, shadcn/ui) y Django REST Framework.

## Backend
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver

## Frontend
cd frontend
npm install
npm run dev
